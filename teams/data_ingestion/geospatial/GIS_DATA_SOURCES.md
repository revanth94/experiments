# GIS Data Sources - India Tiger Reserves

## Overview

This document provides comprehensive information on obtaining **geospatial data (GIS shapefiles)** for India's tiger reserves, including:
- **58 designated tiger reserves** (as of 2026)
- **Core Areas** (critical tiger habitat, strictly protected)
- **Buffer Zones** (peripheral areas with mixed land use)

## Data Availability Status

⚠️ **Important Note**: Comprehensive, publicly downloadable shapefiles for all tiger reserves with core/buffer distinctions are **NOT readily available** in a single unified dataset. Data must be obtained through multiple channels.

### Why Data Access is Limited
1. **Conservation Security**: Detailed location data is sensitive to prevent poaching
2. **Distributed Management**: Each reserve managed by different state forest departments
3. **Varying Digital Infrastructure**: Not all reserves have digitized boundary data
4. **Data Sharing Policies**: Formal requests often required for detailed GIS data

## Primary Data Sources (Official)

### 1. National Tiger Conservation Authority (NTCA)
**⭐⭐⭐⭐⭐ Official Authority - Best Source**

- **Organization**: Ministry of Environment, Forest and Climate Change, Government of India
- **Website**: https://ntca.gov.in
- **Role**: Central authority for all 58 tiger reserves

**What They Have:**
- Official boundaries of all tiger reserves
- Core area and buffer zone delineations
- Management plan maps (may include GIS data)
- Tiger reserve notifications with boundary descriptions

**How to Access:**
- **Step 1**: Visit NTCA website and check Publications/Resources section
- **Step 2**: Look for "Tiger Reserve Management Plans" (often contain maps)
- **Step 3**: Submit formal data request via official channels:
  - Email: Contact through website
  - Address: Bikaner House, Shahjahan Road, New Delhi - 110011
  - State purpose: Research/Conservation/Education
  - Provide institutional affiliation if applicable

**Expected Response Time**: 2-4 weeks for formal requests

## International Data Sources

### 4. Protected Planet (World Database on Protected Areas - WDPA)
**⭐⭐⭐⭐ Global Database - Freely Available**

- **Website**: https://www.protectedplanet.net
- **Managed by**: UNEP-WCMC (United Nations Environment Programme)
- **Free Download**: Yes

**What They Have:**
- Boundaries of protected areas worldwide
- India's national parks, wildlife sanctuaries, tiger reserves
- Global standardized format

**Limitations:**
- May not have detailed core/buffer distinctions
- Boundaries may be generalized
- Data updated periodically (may not reflect latest changes)
- Less detailed than official Indian sources

**How to Download:**
1. Visit https://www.protectedplanet.net/en/thematic-areas/wdpa
2. Search for specific tiger reserve or download India dataset
3. Select shapefile format
4. Free registration required
5. Download includes metadata

**File Format**: Shapefile (.shp), GeoPackage, KML

## Data Structure & Format

### Expected File Formats

| Format | Extension | Use Case |
|--------|-----------|----------|
| Shapefile | .shp, .shx, .dbf, .prj | Standard GIS format (QGIS, ArcGIS) |
| GeoJSON | .geojson | Web mapping, modern GIS tools |
| KML/KMZ | .kml, .kmz | Google Earth, web viewers |
| GeoPackage | .gpkg | Modern alternative to shapefile |

### Expected Attribute Fields

**Tiger Reserve Shapefile Attributes:**
```
- Reserve_Name: Text (e.g., "Corbett Tiger Reserve")
- State: Text (e.g., "Uttarakhand")
- Zone_Type: Text ("Core" or "Buffer")
- Area_sqkm: Numeric (area in square kilometers)
- Notified_Year: Numeric (year of notification)
- TR_Code: Text (unique identifier)
- Legal_Status: Text (National Park, Wildlife Sanctuary, etc.)
- Core_Area: Numeric (core area size)
- Buffer_Area: Numeric (buffer area size)
- Total_Area: Numeric (total reserve area)
```

### Coordinate Reference System
- **Common CRS for India**: 
  - **WGS 84 (EPSG:4326)** - Geographic coordinates (lat/lon)
  - **WGS 84 / UTM zones** - Projected coordinates
    - UTM Zone 43N (EPSG:32643) - Western India
    - UTM Zone 44N (EPSG:32644) - Central India
    - UTM Zone 45N (EPSG:32645) - Eastern India
    - UTM Zone 46N (EPSG:32646) - Northeastern India

## Legal & Ethical Considerations

### Data Usage Guidelines

✅ **Acceptable Use:**
- Research and academic purposes
- Conservation planning
- Education and awareness
- Non-profit conservation initiatives

⚠️ **Restricted Use:**
- Commercial purposes (may require specific permissions)
- Activities that could compromise wildlife security
- Redistribution without proper attribution

### Security Considerations
- Some detailed location data is intentionally restricted
- Core habitat details may be sensitive to prevent poaching
- Always respect data sharing agreements
- Attribute data sources properly

### Right to Information (RTI) Act
- Indian citizens can file RTI requests for government data
- Useful for obtaining data from state forest departments
- Process takes 30-45 days typically
- Nominal fee required

## Current Status: India's Tiger Reserves (2026)

### Reserve Count
- **Total Tiger Reserves**: 58 (as of 2026)
- **States with Reserves**: 20 states
- **Total Area**: ~75,000 sq km (including core and buffer)

### Core vs Buffer Zones

**Core Areas:**
- Strictly protected
- Minimal human activity
- National Parks or Wildlife Sanctuaries
- No human habitation (except with permission)
- ~35,000-40,000 sq km total

**Buffer Zones:**
- Peripheral areas
- Mixed land use allowed
- Forest villages may exist
- Ecotourism permitted
- ~35,000-40,000 sq km total
